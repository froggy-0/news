# 논문 리뷰 히스토리

아레나 개선 리서치 중 참고한 외부 논문의 인사이트를 간단히 기록. 상세 요약이 아니라
"무엇을 얻었고 뭐가 적용됐는지"만 남기는 히스토리용 로그.

- [Palazzi (2025) — 페어트레이딩 논문](palazzi-2025-trading-games.md) — 적용 안 됨(전략군 불일치)
- [Bysik & Ślepaczuk (2026, arXiv:2606.00060) — cost-aware execution filter](bysik-slepaczuk-2026-cost-aware-execution.md) — execution_gate 검증 + 오더북 depth 버그 발견/수정 계기
- [Haroon (2026, arXiv:2607.23370) — RAML 레짐인식 멀티모달 감성융합](haroon-2026-raml-regime-aware-fusion.md) — 개념적 확인만, 미적용
- [Johansson & Sönström (2026) — conformalized classifiers with reject option](johansson-sonstrod-2026-conformalized-reject-option.md) — 미적용(아키텍처·표본크기 불일치)
- [Murphy & Gebbie (2019, arXiv:1903.02228) — 기술매매 온라인학습(UP 계열)](murphy-gebbie-2019-learning-technical-trading.md) — 핵심 아이디어(알고간 자본재배분)는 제품철학과 충돌해 미적용, Min-t 검정만 저비용 후보
