# Haroon (2026), arXiv:2607.23370 — RAML: 레짐인식 멀티모달(가격+감성) BTC 방향예측

## 무엇에 관한 논문인가
BTC 시간봉 가격(BiLSTM)과 Reddit FinBERT 감성(BiLSTM)을 학습가능한 시그모이드 게이트
`w_t = σ(θ_r · r_t)`(r_t=이진 변동성 국면라벨)로 적응적 융합. 정적 concat 대비, 국면에 따라
어느 모달을 더 신뢰할지 게이트가 학습. Ablation으로 감성브랜치·레짐게이트·적응적가중치
셋 다 독립적으로 필요함을 확인(3개 중 하나라도 빼면 성능 붕괴, 특히 concat 대체 시 6h
recall 0.08까지 붕괴).

## 얻은 인사이트
- 핵심 사상 "국면에 따라 신호소스 신뢰도를 다르게 가중해야 한다"는 아레나에 **이미 룰기반
  으로 구현돼 있음** — `multi_factor`의 레짐별 투표조건(WI-1/v32), `omnibus`의 레짐별
  사이즈(1.0/0.40/0.25) 자체가 이 논문의 학습형 게이트를 룰로 대체한 버전.
- 이 논문은 딥러닝 **예측모델**(가격이 갈 방향을 직접 학습)이고 아레나는 **룰기반 신호+게이트**
  구조라 아키텍처가 근본적으로 다름 — 학습가능한 θ_r 하나를 아레나에 이식할 자리가 없음.
- "정적 concat이 오히려 성능을 깎을 수 있다"(B3 static concat이 B2 sentiment-only보다
  3h에서 더 나쁨)는 결과는, 아레나가 W2에서 발견한 "backtest/live 회계 분리 안 하면 왜곡"
  류의 교훈과 결이 비슷 — 구조 정합성 문제는 늘 조용히 성능을 깎는다는 일반론적 확인.

## 적용 여부
**미적용.** 개념 검증(아레나가 이미 옳은 방향으로 가고 있다는 확인)만 하고 코드 변경 없음.
