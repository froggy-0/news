# P2 거래당 엣지/비용 감사 — 고정 사양 경제성 판정 (2026-08-04)

> **상태: 완료 — 4h 포트폴리오 3자산 모두 양쪽 시장창 기준 실패.**
> 알고×자산에서도 통계적으로 확인된 통과 조합은 0건이다. 라이브·shadow 파라미터는
> 변경하지 않았다.

## 1. 질문과 사전 기준

P1 청산정책 가설 0/4와 P4 과최적화 감사 실패 후, 추가 파라미터 탐색 없이 현재 기본
사양이 거래비용을 감당할 경제적 엣지를 갖는지만 확인했다.

- 기준: `gross edge / trading cost ≥ 3`
- 시장창: 상승장 2023-08-04~2024-07-31, 하락장 2024-11-09~2026-07-25
- 자산: BTCUSDT, ETHUSDT, SOLUSDT
- 비용: `arena-cost-v2/base`, 포지션 가중 전 왕복 13bps
- 표본: 거래별 `gross_ret_pct × position_weight`, `trading_cost_pct × position_weight`
- 불확실성: 거래 단위 부트스트랩 5,000회, 95% 구간
- 추론 최소 표본: 시장창별 n≥20

상승장 매크로는 기존 역사 검증 명세대로 FNG와 BTC funding을 재수집해 일별 워크포워드로
재구성했다. FNG·funding·funding z-score 커버리지는 모두 100%였다. VIX와 2023년 당시
존재하지 않거나 보존되지 않은 매크로는 기존 역사 검증과 동일하게 결측 시 미차단이다.

## 2. 포트폴리오 결과

|---|---|---:|---:|---:|---:|---:|---:|---:|---:|

| 하락 | BTC | 417 | +12.59 | 16.45 | -3.87 | 3.02 | 3.95 | **0.76** | [-0.56, 2.10] |

상승장 SOL만 포인트 기준을 넘지만 하락장에서 -0.07로 붕괴한다. BTC는 두 창 모두 비용의
1.15배 이하이고, ETH는 두 창 중 하나 이상에서 gross 자체가 음수다. 따라서 3자산 모두
"양쪽 시장창에서 ≥3" 기준을 충족하지 못한다.

## 3. 알고×자산 예외 검토

양쪽 창에서 포인트 기준을 넘은 조합은 두 개뿐이다.

| 조합 | 상승장 n / ratio / CI 하단 | 하락장 n / ratio / CI 하단 | 판정 |
|---|---:|---:|---|
| BTC `fng_contrarian` | 5 / 17.71 / -3.50 | 52 / 3.32 / -1.78 | 상승장 소표본, 미확인 |
| SOL `multi_factor` | 57 / 5.49 / -1.73 | 67 / 4.80 / -1.31 | 포인트 통과, 통계 미확인 |

BTC `fng_contrarian`은 상승장 5건이라 기준선으로 쓸 수 없다. SOL `multi_factor`는 유일하게
양쪽 창에서 n≥20과 포인트 기준을 함께 만족하지만, 두 창 모두 95% 구간 하단이 3은커녕
0 아래다. 이는 평균이 소수 대형 승리에 의존할 수 있음을 뜻하므로 **고정 사양 관찰 후보**일
뿐 활성화 후보는 아니다.

## 4. 판정

1. 현재 4h 포트폴리오는 시장창을 가로질러 비용 대비 3배의 gross edge를 만들지 못한다.
2. P2를 통과한 알고×자산 조합은 없다. SOL `multi_factor`만 추가 튜닝 없는 독립 holdout
   또는 기존 shadow 관찰 대상으로 남긴다.
3. ETH/SOL shadow의 라이브 승격 근거는 없으며 기존 비활성 상태를 유지한다.
4. 같은 4h 공간의 파라미터 탐색은 P4 결과대로 중단한다.

P1(청산정책), P4(과최적화), P2(경제성)가 모두 닫혔다. 다음 의사결정은 새 4h 파라미터가
아니라 **고정된 1d 주기 비교**다. 1d에서도 양쪽 창 `edge/cost ≥3`과 통계 구간을 확보하지
못하면 현재 전략군의 확장 연구를 종료하는 것이 맞다.

**✅ 2026-08-06 실행 완료 — 1d에서도 3자산 포트폴리오 모두 양쪽 창 기준 실패.** 상세:
[p2-1d-frequency-audit-20260806.md](p2-1d-frequency-audit-20260806.md). 4h·1d 감사가
모두 닫혀, 현재 전략군(4h 6알고 스팟 롱온리) 확장 연구는 종료가 타당하다는 결론이다.
